# Course Summary

1. Read the lesson material supplied by the user or present in the current lesson directory.
2. State three to five observable learning objectives.
3. Explain each key concept in plain language and preserve important technical distinctions.
4. Include at least one runnable exercise using the lesson's existing dependencies.
5. End with three self-check questions. Do not include answers until the learner asks.
